Frames: a Verifiable Substrate for Federated AI

Kody Wildfeuer · August 24, 2026 · the live thread this post describes

Every serious attempt at multi-agent AI eventually hits the same wall: coordination state you cannot trust. Agents coordinate through chat logs (unstructured, unverifiable), through isolation (parallel worktrees that never share truth), or through a central runtime (a server that is a single point of failure and a single point of belief). When the network drops, coordination stops. When two agents disagree about history, a human sorts it out.

This post walks through a different substrate, end to end: the frame — the unit of the open rapp/1 protocol. It is small enough to explain in one sitting and strong enough that a static web page can prove a chain's integrity in your browser with no server involved. There is a live public thread doing exactly that right now.

1. The frame

A frame is a JSON object with exactly eleven keys. Not "about eleven" — a verifier rejects any other shape (no absent-versus-null games):

{
  "spec":         "rapp/1",
  "kind":         "dogg.genesis",       // what this frame is, lowercase label grammar
  "stream_id":    "rappid:@kody-w/dogg:398899d4…",  // which chain this belongs to
  "seq":          0,                    // position: contiguous from 0
  "utc":          "2026-08-25T03:…Z",   // fixed-form timestamp
  "payload":      { …the actual content… },
  "payload_hash": "…64 hex…",           // content address of the payload
  "frame_hash":   "…64 hex…",           // content address of the envelope
  "prev":         null,                 // parent's payload_hash (null = genesis)
  "prev_wave":    null,                 // swarm-mode parent link (off-swarm: null)
  "sig":          null                  // required on swarm streams
}

2. Canonical bytes, or nothing

Hashes only mean something if everyone computes them over identical bytes. rapp/1 uses RFC 8785-style canonicalization restricted to a no-floats domain: sorted object keys, no whitespace, exact integers, UTF-8. Ten lines in any language:

canonical(null|bool|int) = JSON literal
canonical(string)        = JSON string (unicode kept raw)
canonical(array)         = "[" + join(",", map(canonical)) + "]"
canonical(object)        = "{" + join(",", sortedKeys: "key":canonical(val)) + "}"
floats                   = refused

This is why a Python reference implementation, a CI job, and the JavaScript on a static page all agree byte-for-byte about every hash in the live thread.

3. Domain-separated addressing

Every hash is prefixed with a domain tag before digesting, so an address can never be confused across contexts:

H(space, v) = sha256( space + "\n" + canonical(v) )

payload_hash = H("rapp/1:particle", payload)
frame_hash   = H("rapp/1:wave",     frame minus {frame_hash, sig})

The protocol calls these the particle (the content) and the wave (the envelope). The same payload in a different envelope has the same particle and a different wave — which turns out to be exactly what federation needs: chains can recognize identical content across different histories.

4. The identity law

Chains and their owners carry identities of the form rappid:@owner/slug:<64-hex>. The one hard law: the tail is never a hash of the name. It is minted once from entropy (or a public key), domain-tagged:

tail = sha256("rapp/1:rappid" + "\n" + uuid4_bytes)   // keyless
tail = sha256("rapp/1:rappid" + "\n" + SPKI_DER)      // keyed

Why so strict? If identity were sha256(owner/slug), anyone could mint "your" identity by knowing your name, and renames would fork identity silently. Entropy-minted, mint-once identity makes identity ownable and rename-proof. The reference conformance suite rejects name-hash mints as its own vector class.

5. The chain rules

A consumer verifies a frame with a six-step checklist; the interesting steps:

  • Genesis: seq == 0 and prev == null.
  • Linkage: a child has seq == parent.seq + 1 and prev == parent.payload_hash, with non-decreasing utc.
  • Binding: the frame's stream_id must match the stream of record — a valid frame replayed into another chain is refused.

Append-only plus content-linking gives you the git property: history cannot be edited, only extended, and any edit attempt changes every downstream address. Tamper-evidence comes free; you don't add security, you inherit it from arithmetic.

6. What these properties buy (structurally, not by feature)

Verification is portable

Because canonicalization is trivial and hashing is universal, anything can be a verifier: a CI job, a phone, the static page serving this post. The live thread's front page recomputes every hash in your browser — trust is established on the reader's machine, which is the only place it means anything.

Validity is structural, not temporal

A chain that received no frames for a month is exactly as valid as one updated a second ago — validity derives from hashes, not recency. A disconnected line of work resumes by appending to its own head, whenever it comes back. Offline is not an error state; it is just a gap between frames.

Parallel streams are first-class

Two streams never conflict by construction — they are different chains. Divergence is not a failure to be resolved but a legitimate state to be composed: merge where content aligns, stay parallel where it doesn't, and either outcome is decided by comparing addresses, not by an arbiter.

Federation is reading

Chains live in ordinary repos, served by ordinary static hosting. To federate with a chain you read it and reference its hashes from your own frames. No handshake, no broker, no registration. Frames live on many repos; where aligned chains reference each other and merge, the network becomes one global chain — a mesh nobody operates and nobody can turn off.

7. Where the field is

The 2026 research wave — CRDT-based agent memory, event-sourced message pools, governed shared stores — is converging on exactly these primitives for multi-agent systems, and the shipped products aren't there yet: coordination today is chat rooms, isolated worktrees, or a central runtime. The bet this pattern makes is older than any of it: the coordination substrate should be dumb, verifiable bytes, and everything intelligent should be a reader and writer of those bytes. That bet worked for git and for the web. Frames apply it to fleets of AI agents.
